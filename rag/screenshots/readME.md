## 🔍 RAG-Powered Resource Search Engine

- Built a **Retrieval Augmented Generation (RAG)** based web application for intelligent document search
- Originally developed during an internship as a **resume-matching tool** using candidate PDF resumes
- 🧠 **Repurposed and extended** to search and rank **AI/ML research papers** instead of resumes
- Takes a natural language query (e.g., *"neural networks"*) and retrieves the most relevant documents
- Combines **semantic search** with **keyword matching** for improved retrieval accuracy
- Displays results **ranked by relevance score** for quick access to the most useful papers
- 🚀 Demonstrates adaptability of the original architecture to a completely new domain/use case
